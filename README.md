# Homebrew tap for Solara

```sh
brew tap andrewbenson/solara
brew trust andrewbenson/solara
brew install --cask solara
```

Homebrew asks you to trust a third-party tap before it loads its casks.

Solara updates itself through Sparkle once installed. The cask is bumped with every stable release of [andrewbenson/solara](https://github.com/andrewbenson/solara).
